# 专词｜英语专业四级真题精读

直接双击 `index.html` 即可使用。推荐 Edge 或 Chrome。

## 已收录

- 2012-2019、2021-2025 真题
- 2021、2022、2023 补充卷
- 已按要求排除 Dictation 与 Talk / Listening 部分

## 功能

- 按年份、卷型、Part 分组导航
- 每个单词下方显示中文词义，可用顶部“逐词”按钮随时开关
- 点击任意英文单词：自动发音、中文词义、音标、英文释义，以及经过核对的语法句型、常见搭配和固定结构
- 重点词黄色；短语与固定搭配蓝色，并在短语下方显示对应中文意思
- 1714 个正文段落均已生成离线语境译文，无需翻译服务或网络连接
- 生词本支持逐个勾选、全选或全不选；打印、手写和背词时都可自由选择本轮使用哪些生词
- 导出 A4 双向默写卷：可选“左英文、右侧默写中文”或“左侧默写英文、右中文”
- 每份默写卷附独立答案页，统一按“左英文、右中文”排版，不混入音标、文章标题等无关内容
- 默写练习支持“看中文写英文 / 看英文写中文”双向练习，并可自由选择手写作答或键盘输入；同时显示英文解释，并可展开完整中英文答案
- 手写画布支持触控笔、手指和鼠标，可撤销、清空、保存 PNG；不同单词和练习方向分别保存笔迹
- 卡片背词模式：自由选词、每张卡片自动发音、查看音标与英文解释、显示中文，并用“认识 / 再学一次”记录复习情况；自动发音可随时关闭
- 手机、平板和电脑均可使用全部功能；窄屏设备通过右上角“⋯”打开完整工具菜单

## 离线与联网

网站主体、逐词中文、音标、英文释义、短语说明和段落译文均可离线使用。浏览器内置英文语音作为离线发音方式。

如果某个单词的离线用法库没有可靠搭配，打开单词后会尝试访问公共词典补充用法；网络不可用时不影响正文阅读与已有词典内容。在线请求只发送当前单词或短语，不上传真题段落。

查词、生词本、逐词开关和手写内容均只在本机处理。

## 重新生成真题数据

`tools/build_exam_data.py` 会读取原始 PDF，移除听写与听力部分，并生成 `data.js`。2024 扫描卷需要先生成 OCR 文本到 `tmp/ocr/2024-真题.txt`。

`tools/build_offline_lexicon.py` 用于重建离线词库；`tools/build_offline_translations.py` 使用本地 Argos 模型重建段落译文，真题内容不会发送给翻译网站。
